The boundaries, measured with the same instrument

The result is bound to a 4096-byte window. At a 1024-byte carve the same protocol returns CARVE_FAILS: within-size top-1 0.1355 against its own best baseline 0.1256 (margin below the 0.05 bar), and a 4096-trained model transfers at 0.0403 — chance. The byte-identity ceiling barely moves across carve sizes, so this is a modelling failure and is reported as one. Two learned byte-sequence attempts (preregs 0009, 0010) did not rescue it.

The boundary is now bracketed to a factor of two.
